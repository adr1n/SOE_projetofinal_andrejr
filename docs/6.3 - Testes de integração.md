# Testes de Integração

## Instruções

Nesta etapa, os componentes, bibliotecas e algoritmos avaliados anteriormente nos testes de _hardware_ e de _software_ serão integrados para a entrega final:

- Conectem as partes fundamentais.
- Acrescentem recursos básicos de sistema: múltiplos processos e _threads_, _pipes_, sinais, semáforos, MUTEX, recursos de Linux em tempo real etc.
- Desenvolvam em linguagem C e/ou C++.
