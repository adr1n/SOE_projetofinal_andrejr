O projeto Assistente de Voz Residencial consiste em um software em pipeline sequencial orientado a eventos: Wake Word -> STT -> Tradução em Comandos -> Ação -> TTS

## Visão Geral do Algoritmo

O sistema opera continuamente "escutando" o que acontece ao seu redor até ouvir a palavra de ativação (Wake Word). A partir disto, este captura o áudio por até 5 segundos e o salva em arquivo. Este arquivo de audio é então enviado para a nuvem e transformado em texto (STT: Speech To Text).
Com o texto do comando obtido em arquivo, novamente este é enviado à nuvem, onde irá acontecer o Processamento Semântico, sendo transformado em comandos a executar. Assim, são executados os comandos e é sintetizado uma resposta em áudio ao usuário (TTS: Text To Speech).

## Coleta de Dados

O audio é coletado em uma Webcam genérica conectada à porta USB da Raspberry Pi. Este é capturado com uma taxa de amostragem de 16kHz, o que é suficiente para a captura da voz humana, uma vez que estamos seguindo o Teorema da Amostragem de Nyquist-Shannon [1] e é também o suficiente e adequado para reconhecimento de fala [procurar referencia].

## Processamento de Dados

O processamento de dados ocorre em três fases sequenciais (também já abordadas anteriormente):

1. Detecção da Palavra de Ativação (Local / Wake Word)

    - Uma rede neural de detecção de palavra de ativação é executada localmente e continuamente em segundo plano (openWakeWord) para que o comando possa começar a ser gravado assim que detectar uma chamada.

2. Filtragem de Áudio por Energia (RMS) e por Frequência

    - O áudio é capturado com um filtro passa faixa que remove ruídos que não sejam da fala humana. Isto é feito com a biblioteca [CITAR BIBLIOTECA].
    - Antes do áudio ser enviado para o processamento semântico, este é primeiro filtrado para que não faça requisições à API do Gemini caso não venha nada após a palavra de ativação. Assim, calcula-se a raiz do valor quadrático médio do sinal de áudio gravado em memória (numpy.sqrt(numpy.mean(numpy.square(audio)))) e caso o volume do áudio esteja abaixo de um valor de limiar, este é descartado. 

3. Processamento Semântico

    - Após obter o comando de voz transcrito em texto, é necessário extrair a ação solicitada e traduzir isto em comandos de software. Para isto, será utilizada uma API da LLM Gemini que irá receber o texto do comando de voz e informações adicionais para responder um arquivo em formato JSON contendo os comandos.

    O arquivo JSON é estabelecido no seguinte formato:

## Atuadores

Como atuadores, o sistema possui apenas um autofalante, uma vez que o acionamento da lâmpada será feito por wi-fi.
Assim, só será necessário alimentar a caixa de som via USB e conectá-la à saída P2 do Raspberry Pi
