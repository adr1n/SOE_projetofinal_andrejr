# Projeto Conceitual de _Hardware_

A descrição do _hardware_ deve permitir que outras pessoas consigam reproduzir o produto desenvolvido. Para isso, apresentem uma descrição dos principais subsistemas e justifiquem as escolhas de projeto.

Tópicos importantes a serem descritos incluem:

- **Processamento:** RPi 3, Arduino, MSP430 etc.
- **Sensores:** tipos (temperatura, pressão etc.), taxas de amostragem e precisões necessárias;
- **Atuadores:** motores DC, relés, LEDs etc.
- **Comunicações:** UART, I2C, SPI, USB, WiFi, Bluetooth etc.
- **Armazenamento:** _hard drive_, cartão SD, _pendrive_ etc.
- **Interfaces com o usuário:** botões, LEDs, _display_, _touchscreen_ etc.	
- **Estrutura física:** formato, dimensões, posicionamento dos circuitos, dos sensores, dos atuadores e da interface com o usuário.
 
Incluam obrigatoriamente um **diagrama de blocos**, um **esquemático** e uma **lista de materiais com orçamento e consumo energético**. 

## Diagrama de Blocos

O diagrama de blocos apresenta uma visão geral do hardware, seus principais subsistemas e as conexões entre eles, para facilitar o entendimento do circuito desenvolvido.

## Esquemático

Outro item obrigatório é o **esquemático elétrico**, mostrando:

- Componentes utilizados;
- Símbolos elétricos;
- Conexões entre os componentes;
- Pinagem dos dispositivos.

Reparem que o diagrama de blocos indica os sub-sistemas do circuito completo apresentado no esquemático.

![Esquemático](https://raw.githubusercontent.com/fcte-pi1/template/refs/heads/main/docs/figs/Esquematico.png)

**Figura 2.** Esquemático de um circuito conversor de corrente alternada para corrente contínua [1].

> **Importante:** ligações em _protoboard_ não são consideradas esquemáticos.
