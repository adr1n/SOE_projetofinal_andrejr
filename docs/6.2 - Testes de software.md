# Testes de Software

## Instruções

Nesta etapa, serão feitos os testes de bibliotecas e algoritmos na placa Raspberry Pi:

- Utilizem _software_ fundamentais ao projeto, de acordo com o projeto proposto (por exemplo, envio de e-mail, reconhecimento facial, redes neurais etc.);
- Demonstrem que é possível utilizar cada uma destas com o Raspberry Pi.
- Nesta entrega, é permitido utilizar linguagens interpretadas (Python, Octave etc.) e programas prontos.
